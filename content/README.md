# Content

Production workspace for Run it Back — the plan and the actual posts.

- **`content-strategy.md`** — the launch plan: positioning, **differentiation**, content pillars, signature series, format, platforms & cadence, funnel, and the 30-day sprint.
- **`growth-and-monetization.md`** — the execution playbook: differentiation wedges (the "comeback" niche-down), the growth engine (hooks/retention/series/platform roles), and the **affiliate map** (pillar→product paths, program shortlist, distribution, FTC).
- **`gear-affiliate-map.md`** — the designer-angle product + affiliate map for the **"The Gear"** pillar: focus hardware (Brick…), wearables (Oura/Whoop), fitness/desk gear, with programs/rates/networks. Design-icons vs money-makers, starting lineup, content↔pain mapping, guardrails.
- **`proven-templates.md`** — beat-by-beat blueprints reverse-engineered from the niche's biggest viral outliers (the "Comeback Cut" + the "Listicle"), with Run it Back adaptations. Our two lead formats.
- **`scripts/`** — ready-to-shoot short-form scripts (hook → VO → on-screen text → visuals → CTA), batched.
