# Comeback Cut #01 — Script v2 (refined)

Refinement pass on `edit-sheet.md` (v1), 2026-07-18. v1 assets (VO, frame cards, Pexels links)
still usable — this doc changes the script, timing, and ending. If v1 already shipped, treat
this as the template for Comeback Cut #02 instead.

## What changed from v1, and why

1. **~26s → ~15s.** The source template (Template A, the 877K/379× outlier) is 8–12s. v1
   doubled it. First post from a zero-follower account = completion rate is the whole ballgame.
   Target ≤15s including sign-off.
2. **One idea only.** Cut the aMCC "part of your brain" line — it's a second concept, and it's
   already script #1 in `launch-batch-01` where it gets a full video. Never miss twice IS the video.
3. **Silent open trimmed 3s → 2s** and the hook rides on the locker-room *clip* (text overlay),
   not the static `frame-hook.png`. A frozen card reads as an image post in a video feed; motion
   + text stops the scroll better. (Keep the card as the feed thumbnail/cover instead.)
4. **Built to loop.** Last spoken line is now "…you're running it back," which flows straight
   into the opening "Good." on replay — rewatches read as retention to the algorithm. So: **no
   3s static end card.** Sign-off (`↻ run it back` + @handle) is a small overlay on the final
   shot, last ~1.5s, video ends mid-motion.
5. **B-roll note:** generic battle-ropes/dark-lift stock is the faceless-motivation aesthetic we
   position against. Acceptable for v1 speed; first upgrade = swap the middle beat for the
   calendar/notebook practical insert (one ✗, then a ✓ the next day) from the Saturday shoot list.
