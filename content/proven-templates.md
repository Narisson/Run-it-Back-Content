## Template A — "The Comeback Cut"
**Source:** @cyrusliftss — "I haven't been consistent in the gym" → **877K views (379× median)** on a 4.3K-follower account. *The single most on-brand winner — this is Run it Back in template form.*

**Why it works:** it opens with the viewer's *exact excuse* (instant relatability), then hits an
emotional **whiplash** — a hard cut from calm→gritty and music→raw voice — that stops the scroll.

**Beat structure (~8–12s):**
1. **0–2s — The excuse (relatable hook).** Calm/neutral B-roll (someone tired, sitting, phone in hand). On-screen text = the viewer's failure state in quotes. Soft music only, **no VO yet.**
2. **2–3s — The drop.** HARD CUT to dark, high-contrast, gritty footage. Music cuts out. Pattern interrupt.
3. **3–8s — The wake-up.** Raw, direct, second-person VO ("you"). Intense, no background music (or low). This is the confrontation/turn.
4. **8–12s — The rule + sign-off.** Land one actionable line + "↻ run it back."

**Production:** bright/soft Higgsfield B-roll → dark/gritty B-roll; VO in our voice; the music→voice cut is the key move. Burned-in captions.

**Run it Back adaptation (example script):**
- **0–2s** (calm, text): *"I fell off. Again."*
- **2–3s** (hard cut, music drops)
- **3–8s** (raw VO): *"Good. Everybody falls off — that's not the story. The story is what you do next. You don't need motivation. You need one rule: never miss twice."*
- **8–12s** (VO + text): *"You missed yesterday? It's gone. Win today. That's the whole game."* → **↻ run it back.**
- *Optional science tag (our differentiator):* *"And every restart isn't back to zero — it's a rep for the part of your brain that makes discipline stick."*

## Template B — "The Listicle"
**Source:** @_darrenhugo_ — "10 uncomfortable signs you were born for GREATNESS" → **343K views (76× median)** on a 2K-follower account.

**Why it works:** curiosity + flattery in the hook ("signs you [aspirational identity]"), a numbered
list that drives **saves**, moody training B-roll, and a payoff twist. Uses **AI text-to-speech VO** —
confirming faceless AI voice performs fine in this niche.

**Beat structure (~20–30s):**
1. **0–2s — Hook held on screen the whole video:** "[N] uncomfortable signs you [identity]." VO reads it.
2. **2–end — The list.** Each item = one line of VO over a moody, single-shot cinematic B-roll clip (night training, dawn, cold water, walking). Beat drops on/after the hook for energy.
3. **Payoff twist at the end** (@_darrenhugo_: "your next opponent is… you").
4. **Sign-off:** "↻ run it back."

**Production:** AI VO (vidiQ `voiceover_generate` or Higgsfield) + 6–10 Higgsfield B-roll clips, moody directional lighting, one beat-drop track. Static hook text + dynamic captions. High save-rate format.

**Run it Back adaptation (example script — comeback flavored):**
Hook: *"7 signs you're built for the comeback"*
1. *"You've failed more times than most people have tried."*
2. *"You feel behind — which means you can still see how far you want to go."*
3. *"You've started over so many times that starting doesn't scare you anymore."*
4. *"You don't want easy. You want to earn it."*
5. *"The version of you that quit still haunts you. Use him."*
6. *"You're tired of talking about it."*
7. *"You watched this to the end. The comeback already started."* → **↻ run it back.**
