# Visual Identity — Exploration v1

Three brand-identity directions for Run it Back, all built for the **male-discipline core**
(18–34) and deliberately different from the competitors we studied (shadowgrindx_'s teal
starburst; goodmindsquote's vintage paper).

**Shared logic across all three:** the name "Run it Back" *is* the **replay/loop mark (↻)** —
an instantly ownable logo. Every direction also uses one dark base + one signal accent + the
**"↻ run it back."** sign-off.

| Direction | Personality | Leans toward | Accent |
|---|---|---|---|
| **A — Blueprint** | Analytical, technical, credible | the *mechanism/science* differentiator | electric blue `#3B82F6` |
| **B — Concrete** | Brutalist, gritty, athletic | the young-male grind core | blaze orange `#FF4A1C` |
| **C — Nightfall** | Cinematic, premium, emotional | Optimizer + health crossover, product sales | ember gradient (dawn/comeback) |

Each `.svg` is a brand board: logo + palette (with hex) + type specimen + a sample post +
a note on *why it works*. Production fonts noted per direction (swap in from the design
bundle once a direction is chosen); boards use safe fallbacks so they render anywhere.

Once a direction is picked, it becomes the `run-it-back-brand` skill (rewritten from the
parked `brand-guidelines` skeleton) so every future asset is auto-consistent.
