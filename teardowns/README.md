# Teardowns

Competitor / inspiration brand analyses, produced by the `brand-teardown` skill.

Each file reverse-engineers another brand's content strategy (positioning, pillars,
hooks, cadence, voice, funnel/monetization) and ends with concrete **Steal / Adapt /
Avoid** moves for Run it Back.

Naming: `<brand-handle>-<mode>-<yyyy-mm-dd>.md` (mode = `quick` or `deep`).
